## Sobre o projeto

O site apresenta informações do filme, vídeo de fundo e um modal para assistir ao trailer oficial. A interface se adapta a computadores, tablets e celulares.

## Como funciona

- Layout responsivo sem rolagem horizontal.
- Vídeo de fundo em telas maiores.
- Modal de trailer acessível por mouse e teclado.
- Fechamento pelo botão, pela tecla `Esc` ou pela área externa.
- Navegação interna e indicadores de foco visíveis.
- Imagens com textos alternativos.

## Tecnologias

- HTML5 para a estrutura.
- CSS3 para identidade visual e responsividade.
- JavaScript para controle do trailer.
